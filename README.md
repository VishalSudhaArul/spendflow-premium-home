# SpendFlow

A premium personal finance product landing page and interactive dashboard concept created for the Acdyon Technologies Frontend Challenge — Part 2: The Premium Home Page.

## Features
- Premium responsive landing page
- Interactive dashboard preview
- Spending trend visualization
- Period comparison
- Category breakdown
- Recent transactions
- Insights section
- Responsive mobile navigation
- Smooth section navigation
- Interactive chart tooltips
- Responsive design for 390px and 1440px viewports

## Tech Stack
- React
- TypeScript
- Vite
- Tailwind CSS
- Lucide React

## Run Locally

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

## Design
SpendFlow features a restrained, modern fintech visual system built around visual clarity and calm financial perspective:

- **Background:** `#F7F8FC`
- **Primary Ink:** `#111827`
- **Secondary Text:** `#667085`
- **Primary Violet Accent:** `#635BFF`
- **Accent Hover / Deep:** `#4338CA`
- **Soft Accent:** `#EEF2FF`
- **Borders:** `#E5E7EB`
- **Success State:** `#16A34A` (used exclusively for positive percentage indicators)

### Typography
- **Fraunces:** Optical variable display serif for autoritative headings
- **Inter:** Clean sans-serif for UI, numbers, controls, and financial records

## Demo Data
All financial figures, budget totals, trend charts, category breakdowns, and transaction logs displayed in SpendFlow are **illustrative demo data** designed to demonstrate the user experience, interface hierarchy, and interactive mechanics of the application. They do not represent real user financial information.
